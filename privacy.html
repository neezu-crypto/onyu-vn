제1조 (기본 원칙)

오목지면시그(이하 “운영자”)는 서비스 제공에 필요한 정보만 처리하며, 수집 목적이 달성되거나 이용자의 삭제 요청이 있으면 관련 법령이 정한 범위에서 지체 없이 정리합니다.

제2조 (처리하는 정보와 목적)

정보처리 목적
Firebase 인증 UID·로그인 제공자로그인 상태 확인, 게임 접근 권한과 진행 계정 연결
후원자 닉네임일반 유저의 후원 승인 신청 확인 및 관리자 검수
방송 닉네임·SOOP 아이디스트리머 인증 신청과 실제 방송 계정 대조
게임 이벤트·접속 기록서비스 운영, 오류 분석, 이용 통계와 중복 요청 방지
브라우저 저장 데이터게임 세이브, 설정, 갤러리 해금과 시그니처 오프닝 표시 주기 관리

제3조 (외부 서비스 및 제공)

  • Firebase·Google Cloud: 인증, Realtime Database, Cloud Functions, 접속·통계 데이터 처리
  • Google·Kakao: 이용자가 선택한 로그인 인증
  • SOOP: 이용자가 직접 후원하거나 제출한 방송 계정 확인을 위한 외부 서비스
  • Discord: 후원 승인·스트리머 인증 신청이 있을 때 관리자 알림 전송

운영자는 광고 목적 등으로 이용자 정보를 판매하지 않습니다.

제4조 (보유 기간)

  • 접근 승인·스트리머 인증 신청 정보는 검수와 운영 이력 관리에 필요한 기간 동안 보관합니다.
  • 집계용 일일 통계는 최대 400일, 원본 이벤트 기록은 최대 30일을 기준으로 정리합니다.
  • 브라우저에 저장되는 세이브·설정·갤러리 정보는 이용자가 직접 삭제하거나 브라우저 저장소를 초기화할 때까지 남을 수 있습니다.

제5조 (이용자의 권리)

이용자는 본인과 관련된 정보의 열람·정정·삭제를 요청할 수 있습니다. 요청 시 본인 확인에 필요한 최소한의 정보를 함께 알려주시면 확인 후 처리합니다. 문의: skftodwocks2@gmail.com

접근 권한이 필요한 처리는 서버 함수에서 확인하고, 데이터베이스 보안 규칙으로 직접 접근을 제한합니다. 본 방침은 서비스 기능이나 관련 법령이 변경될 때 개정될 수 있으며, 변경 내용은 이 페이지에 반영합니다.

본 문서는 서비스의 실제 처리 항목을 기준으로 작성한 안내입니다. 법률상 별도 고지가 필요한 경우 관련 법령과 운영자 안내가 우선합니다.
