# 온이유 일러스트 교체 프롬프트

작성일: 2026-10-14

## 검토 범위와 기준

현재 저장소의 그림을 연락표로 모두 확인하고, 게임 데이터의 실제 사용처를 대조했다.

- 스탠딩 일러스트 78장: 기본 교복·계절복 24장, 선택 의상 48장, 졸업 가운 6장
- 이벤트 CG와 표지 36장: 챕터 CG, 의상별 CG, 학년 전환 CG 2장, 엔딩 CG 3장, 표지
- 스탠딩 표정 번호는 엔진 기준으로 1 차분, 2 미소, 3 놀람, 4 수줍음, 5 걱정, 6 새침함이다.
- CG 장면명과 연결은 js/game-data.js의 챕터·의상·학년 전환·엔딩 매핑과 대조했다.

캐릭터 외형의 기준 이미지는 `assets/standing/s1.png`다. 온이유는 은백색에 연보라빛이 도는 긴 머리의 높은 포니테일, 큰 짙은 남보라색 머리 리본, 붉은 눈, 양 볼의 붉은 사선 자국과 가는 수염 모양 선이 특징이다. 다른 스탠딩 이미지도 같은 인물의 얼굴·머리·눈·볼 자국 디자인을 따른다. 스탠딩 원본에 꼬리가 있더라도 앞으로 생성하는 CG에는 꼬리를 넣지 않는다. CG 생성 시 의상에 맞는 `assets/standing/` 스탠딩 일러스트를 캐릭터와 의상 참고로 사용하고, 원본 CG는 화면 구도·카메라·몸 방향·자세·소품 배치 참고로만 사용한다. 기존 그림을 재사용하거나 트레이싱하지 않고 새 장면으로 생성한다. 이 문서의 장면 세부 내용과 사용자의 최신 지시가 충돌하면 사용자의 지시를 우선한다.

## 프롬프트 조립 방법

스탠딩 파일마다 다음 세 부분을 이어 붙여 하나의 프롬프트로 사용한다. 온이유의 얼굴·헤어·눈·볼 자국·꼬리는 `assets/standing/s1.png`를 기준으로 일관되게 유지하고, 각 의상 세트 설명에 맞는 옷을 입힌다.

1. 아래 공통 인물·화풍 블록
2. 해당 의상 세트 블록
3. 파일별 표정·포즈 한 줄

CG는 공통 CG 블록과 파일별 장면 프롬프트를 이어 붙인다. CG를 생성할 때마다 장면 의상에 맞는 `assets/standing/` 스탠딩 일러스트를 캐릭터와 의상 참고로 사용한다. 학년과 관계없이 앞으로 생성하는 모든 CG에서 꼬리를 생략한다. 원본 CG는 구도·카메라·몸 방향·자세·소품 배치 참고로만 사용한다. 결과 이미지는 새로 생성하며 기존 그림을 재사용하거나 트레이싱하지 않는다. 무료·꾸민 의상 변형 CG는 같은 장면을 유지하면서 각각 지정 의상을 적용한다. 이미지 안에 문구나 로고를 생성하지 않는다. 학교 간판 등 꼭 필요한 한국어 글자는 그림 생성 후 별도 편집한다.

## 공통 인물 블록

온이유라는 이름의 한국 고등학생 캐릭터. 차분하고 관찰력이 좋으며 그림 그리기와 게임을 좋아한다. 캐릭터 외형은 `assets/standing/s1.png`를 기준으로 한다: 은백색에 연보라빛이 도는 긴 머리를 높은 포니테일로 묶고, 포니테일에는 큰 짙은 남보라색 리본을 단다. 붉은 눈, 둥근 타원형 얼굴, 양 볼의 붉은 사선 자국과 가는 수염 모양 선, 풍성한 흰 여우 꼬리를 일관되게 유지한다. 장면에 따라 꼬리가 프레임 밖으로 나가더라도 보이는 경우에는 같은 디자인으로 표현한다. 새 캐릭터로 재해석하거나 짙은 밤색 단발·호박색 눈·청록 실핀·주근깨로 바꾸지 않는다. 고등학생에 맞는 단정한 복장과 비성적인 연출을 유지한다.

## 공통 스탠딩 화풍·출력 블록

고품질 2D 비주얼 노벨 캐릭터 원화, 섬세하고 깨끗한 선화, 부드러운 셀 채색과 절제된 회화풍 음영, 자연스러운 피부색, 읽기 쉬운 표정. 세로 2:3 비율의 투명 배경 PNG, 인물 한 명만, 머리부터 허벅지 중간까지 보이는 3/4 전신, 인물 크기와 카메라 높이를 모든 표정 파일에서 동일하게 유지. 정면에서 약간 비껴 선 자연스러운 시선, 손가락과 의상 주름을 정확하게 표현. 학교 생활극에 맞는 단정하고 비성적이며 연령에 맞는 복장. 글자, 워터마크, 로고, 테두리, 소품 추가, 배경색, 바닥 그림자, 다른 인물은 넣지 않는다.

## 공통 CG 화풍·출력 블록

독창적인 2D 비주얼 노벨 시네마틱 일러스트, 가로 16:9 화면, 정교하지만 과장되지 않은 선화, 부드러운 회화풍 배경과 선명한 캐릭터, 자연스러운 계절 조명, 따뜻하고 절제된 색감, 이야기의 감정을 전달하는 영화적 구도. `assets/standing/s1.png`의 캐릭터 정체성과 장면 의상에 맞는 스탠딩 참고 이미지를 반영한다. CG에서 꼬리는 1학년 장면까지만 표현하며, 2학년 진입 이후에는 풍성한 흰 여우 꼬리를 포함해 어떤 꼬리도 그리지 않는다. 장면에 필요한 경우 플레이어는 얼굴이 보이지 않는 흐릿한 어깨·손 실루엣으로만 나타난다. 등장인물은 고등학생으로 연령에 맞게 묘사하고 신체를 성적으로 강조하지 않는다. 화면 안에는 글자, 자막, 워터마크, 상표, 판독 가능한 간판 문구를 만들지 않는다. 기존 CG는 구도와 자세 참고로만 사용하고 캐릭터를 복사하거나 트레이싱하지 말고 서사 상황을 새 그림으로 구성한다.
