# 온이유 일러스트 교체 프롬프트 초안

작성일: 2026-10-13

## 검토 범위와 기준

현재 저장소의 그림을 연락표로 모두 확인하고, 게임 데이터의 실제 사용처를 대조했다.

- 스탠딩 일러스트 78장: 기본 교복·계절복 24장, 선택 의상 48장, 졸업 가운 6장
- 이벤트 CG와 표지 36장: 챕터 CG, 의상별 CG, 학년 전환 CG 2장, 엔딩 CG 3장, 표지
- 스탠딩 표정 번호는 엔진 기준으로 1 차분, 2 미소, 3 놀람, 4 수줍음, 5 걱정, 6 새침함이다.
- CG 장면명과 연결은 js/game-data.js의 챕터·의상·학년 전환·엔딩 매핑과 대조했다.

현재 그림에는 은빛 또는 연보라색 긴 머리와 높은 포니테일, 큰 보라색 리본, 붉은 눈, 일부 그림의 하트 모양 볼 점·둥근 안경이 반복된다. 이 문서의 새 주인공 기준은 이 시각 조합을 가져오지 않는다. 기존 파일은 장면의 서사 기능과 계절·의상 종류를 파악하는 용도로만 참고하고, 얼굴·헤어 실루엣·포즈·화면 배치를 따라 그리거나 이미지 입력으로 복제하지 않는다.

## 프롬프트 조립 방법

스탠딩 파일마다 다음 세 부분을 이어 붙여 하나의 프롬프트로 사용한다.

1. 아래 공통 인물·화풍 블록
2. 해당 의상 세트 블록
3. 파일별 표정·포즈 한 줄

CG는 공통 CG 블록과 파일별 장면 프롬프트를 이어 붙인다. 무료·꾸민 의상 변형 CG는 같은 장면을 유지하면서 각각 지정 의상을 적용한다. 이미지 안에 문구나 로고를 생성하지 않는다. 학교 간판 등 꼭 필요한 한국어 글자는 그림 생성 후 별도 편집한다.

## 공통 인물 블록

온이유라는 이름의 독창적인 한국 고등학생 캐릭터. 차분하고 관찰력이 좋으며 그림 그리기와 게임을 좋아하는 성격. 짙은 밤색의 턱선 아래까지 오는 단정한 단발, 자연스러운 옆가르마와 가벼운 잔머리, 왼쪽 관자놀이의 작은 청록색 실핀 하나. 짙은 호박색 눈, 둥근 타원형 얼굴, 부드러운 직선 눈썹, 콧등의 옅은 주근깨 세 점. 모든 이미지에서 얼굴형·눈 색·머리 길이·실핀 위치를 일관되게 유지한다. 포니테일, 은발·보라색 머리, 큰 머리 리본, 붉은 눈, 하트 모양 볼 점은 사용하지 않는다. 안경은 기본 디자인에 포함하지 않는다. 기존 작품이나 특정 캐릭터를 연상시키는 복제·트레이싱 없이 독립적으로 디자인한다.

## 공통 스탠딩 화풍·출력 블록

고품질 2D 비주얼 노벨 캐릭터 원화, 섬세하고 깨끗한 선화, 부드러운 셀 채색과 절제된 회화풍 음영, 자연스러운 피부색, 읽기 쉬운 표정. 세로 2:3 비율의 투명 배경 PNG, 인물 한 명만, 머리부터 허벅지 중간까지 보이는 3/4 전신, 인물 크기와 카메라 높이를 모든 표정 파일에서 동일하게 유지. 정면에서 약간 비껴 선 자연스러운 시선, 손가락과 의상 주름을 정확하게 표현. 학교 생활극에 맞는 단정하고 비성적이며 연령에 맞는 복장. 글자, 워터마크, 로고, 테두리, 소품 추가, 배경색, 바닥 그림자, 다른 인물은 넣지 않는다.

## 공통 CG 화풍·출력 블록

독창적인 2D 비주얼 노벨 시네마틱 일러스트, 가로 16:9 화면, 정교하지만 과장되지 않은 선화, 부드러운 회화풍 배경과 선명한 캐릭터, 자연스러운 계절 조명, 따뜻하고 절제된 색감, 이야기의 감정을 전달하는 영화적 구도. 공통 인물 블록의 새 디자인을 그대로 적용한다. 장면에 필요한 경우 플레이어는 얼굴이 보이지 않는 흐릿한 어깨·손 실루엣으로만 나타낸다. 등장인물은 고등학생으로 연령에 맞게 묘사하고 신체를 성적으로 강조하지 않는다. 화면 안에는 글자, 자막, 워터마크, 상표, 판독 가능한 간판 문구를 만들지 않는다. 기존 그림을 그대로 재현하지 말고 서사 상황만 살려 독립적인 장면으로 다시 구성한다.

## 적용 전 체크리스트

- 동일 인물의 머리 길이·밤색·호박색 눈·청록 실핀 위치가 모든 파일에서 유지되는지 확인한다.
- 스탠딩은 투명 배경을 사용하고, 같은 의상 세트 안에서 캔버스 비율·인물 크기·카메라 높이를 통일하며 손과 얼굴의 정상적인 형태를 확인한다.
- 게임이 읽는 6개 표정의 감정이 서로 구분되는지 확인한다.
- CG는 16:9 가로 구도이며 챕터의 서사 장면과 맞는지 확인한다.
- 이미지 모델이 만든 문자·로고·워터마크는 제거하고, 필요한 문구는 별도로 편집한다.
- 인물 외형 참조에는 승인된 공통 캐릭터 기준 이미지만 사용한다. 사용자가 특정 의상 참고 이미지를 제공한 경우에는 지정된 의상 형태만 참고하고 얼굴·머리·포즈·배경은 복사하지 않는다. 결과가 새 공통 캐릭터 기준과 다르면 해당 파일을 다시 생성한다.

이 문서는 교체 대상의 프롬프트와 파일 대응표다. S·W·G·A·C1·P1·C13·P13·C16·P16·C24 스탠딩 세트의 생성과 파일 교체를 완료했으며, 나머지 이미지는 작업별로 진행한다.
