# 당신이 여기에 온 이유

고등학교 1학년, 같은 반이지만 초면인 두 사람이 3년의 계절을 함께 지나는 힐링 비주얼노벨입니다.

## 플레이

- [게임 시작](https://neezu-crypto.github.io/onyu-vn/)
- 27개 챕터와 우정·썸·연인 엔딩
- 이벤트 CG 갤러리, 저장·불러오기, BGM·SFX, 시그니처 오프닝 지원
- Google·Kakao 로그인 및 스트리머 인증 지원

Google 또는 Kakao 로그인 사용자와 인증 스트리머는 이용권 없이 무료로 플레이할 수 있습니다. 로그인하지 않은 미인증 게스트는 로그인하거나 스트리머 인증을 완료해야 합니다. 새 이용권 구매·선물 신청은 종료됐으며, 과거 이용권과 이미 접수된 신청은 관리 및 기존 요청 마무리를 위해 보존되지만 게임 접근 권한에는 사용되지 않습니다.

인증 스트리머는 연인 엔딩 이후 플레이 후기를 작성하지 않아도 본인 미연시 제작 문의를 제출할 수 있습니다. 펀딩금을 모금해 운영자에게 전달하면 제작을 진행하며, 문의는 관리자센터와 Discord 알림으로 확인합니다.

## 기술

별도 빌드 도구 없이 HTML·CSS·JavaScript로 구성된 정적 웹 게임입니다. GitHub Pages로 배포하며, Firebase Authentication·Realtime Database·Cloud Functions를 로그인, 무료 접근 확인, 스트리머 인증, 후기와 통계에 사용합니다. 기존 이용권 신청 기록은 이미 접수된 요청을 마무리하는 데만 사용합니다. 이용약관과 개인정보 처리방침은 [이용약관](terms.html), [개인정보 처리방침](privacy.html)에서 확인할 수 있습니다.
